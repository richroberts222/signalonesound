# Outline data sources

`world.json` (177 countries) and `us-states.json` (50 states plus the District of Columbia) are the Natural Earth
1:110m "Admin 0 - Countries" and "Admin 1 - States, Provinces" vector data, which are in the **public domain**
(https://www.naturalearthdata.com/about/terms-of-use/). They were reduced to each region's name, a code and its
polygons (longitude, latitude), rounded to two decimals. The outlines are deliberately simplified, so coastlines and
borders are approximate to roughly ten miles; the Fire Map page says so in its "How we count" note.
