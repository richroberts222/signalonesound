# Product Analytics (Idea)

Not a requirement. See `README.md`. No vendor is selected; nothing is installed without an authorizing issue.

## Possible questions to answer

* most-used workflows
* least-used workflows
* navigation paths
* interaction frequency
* drop-off points
* feature discovery
* areas users rarely reach

## Considerations for any future evaluation

* Must work across Web, Android, and iPhone consistently (one platform, `CLAUDE.md` section 1).
* Privacy first: collect the minimum, keep personal data and secrets out of events, document consent and retention.
* Prefer workflow-level events over raw click streams.
* Vendor-neutral event naming so a provider can be replaced.
* Compare free/low-cost options when authorized.
