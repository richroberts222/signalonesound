# Heatmaps and Session Analytics (Idea)

Not a requirement. See `README.md`. No tool is selected.

## Possible investigation

Privacy-appropriate heatmaps and/or session analytics to understand where users interact and navigate. Any investigation must cover masking of sensitive fields, consent, retention, and the cost of collecting data on every client.

## Interpreting low usage

Low usage must NOT automatically be interpreted as lack of user interest. It may indicate:

* poor discoverability
* difficult navigation
* broken functionality
* usability problems
* genuinely low customer interest

These signals should trigger human review, not automatic conclusions or automatic feature removal.
