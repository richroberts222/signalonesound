## Task D: confidence and next steps

**Confidence that the foundation is solid enough to start the first real feature: 85% (unchanged).** This pass changed nothing: nothing new was found broken, and nothing on the open list closed. The two thin items (8 and 16) are small and would not move the number on their own.

Top three things I would do next:

1. **Close the zero-cost owner actions before anything else:** GitHub security settings (already open) and two-factor on the owner's GitHub account. Both take minutes, cost nothing, and protect the thing that controls everything else.
2. **Write the two "comes with the first feature" guards before the first feature:** the test-id lint (item 8) and the `axe` accessibility check in Playwright. Guards promised for "the first feature" are the ones the first feature skips.
3. **Decide the attendee privacy posture and the retention schedule (idea C-2 plus the open retention item) before any feature stores a user-to-event link,** and wire free-tier error tracking with log redaction (idea B observability, cheap half). After that, start the first feature.
